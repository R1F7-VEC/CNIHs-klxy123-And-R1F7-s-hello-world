1.1 变量：一个给数据命名的tag

可以把它看作一个数据的标签 当然，它指代的数据会变
举一个例子(伪代码)：
name = "Dick"
age = 25
在这个例子中，name指的是"Dick"这个字符串(就是由字、字母、数字的一个组合)"Dick"，age指的是25这个数
核心规则：变量本身不存数据，只指向数据 你执行age=26时只是让age不再指向25而是指向26

1.3 列表/数组(python这么叫)/表(lua这么叫)：有序集合

这里因为列表和数学内的"集合"概念相似，故先阐述集合概念：

定义1 一个要被用于研究的对象叫做元素(元素可以为任何事物，如一个开发者、一个数字等)

定义2 集合是由若干确定的、互不相同的元素组成的整体

因此，集合有如下性质：
1.确定性 集合内元素必须是确定的，范围不能是模糊的 例如：一个集合不能是"67班所有个子高的同学的名字"(没有明确的个子高矮的分界线)

2.互异性 集合里面无重复元素 取两个元素的并集(合并两个集合)时重复元素会自动删去

3.无序性 集合内元素无顺序
因此集合与数组的区别为：一个有顺序，一个无顺序 因此集合内没有索引一说

元素用小写字母表示（x），集合用大写字母表示（A）

描述一个集合有如下三个方法：
1.列举法 列举出一个集合内所有元素 如：A = ｛6767，6969，6161｝
2.图示法 用一个封闭图形表示一个集合
3.描述法 描述法遵循如下原则：
概括原则 对任给的性质P，存在集合S，它的元素都是具有性质P的对象，即
S = ｛x | P(x)}
其中P(x)表示x具有性质P
集合中的元素是有限个则称此集合为有限集，否则为无限集
我们称一个集合(X)的元素个数为集合的阶，即|X|

这么描述元素与集合间的关系：
1.属于（∈）
2.不属于（∉）

我们这么描述集合间的关系：
1.包含于（⊆） （A的每个元素都能在B内找到）如果A ⊆B，则A是B的子集 如果又有B的元素不属于A，则A是B的真子集（A ⫋B） 不包含于即⊈
2.包含（与包含于相反）

集合有如下运算：(因为纯txt文档所以无符号 需自查)
1.交集 取集合相交元素部分组成新集合
2.并集 取两集合内所有元素组成新集合
3.补集 令一个全集U(放下所有要研究对象的集合)，再令一个包含于全集的集合A，则A在U内的补集(Cu(大写)A)是集合U删去集合A所有元素剩下的元素组成的新集合
4.差集 假设有两个集合A与B有相交的部分，那么A与B的差集A-B表示A剔除与B相交的部分剩下的元素组成的集合
5.对称差 同4内定义的两个集合，则对称差就是A-B与B-A的交集
6.笛卡尔积 两个集合A={x, y, z} B={a, b, c} 那么两个集合的笛卡尔积A×B={(m, n) | m属于A, n属于B}
且|A×B|=|A|×|B|

列表用于存储一组有序的数据，可以用索引(位置)来访问其中的元素

再讲数组：
数组是一种数据结构，用于存储多个属性相同的元素

拿一段python代码举例子：(相信我，你绝对看得懂)

memes_67 = ["67", "61"]
print(memes_67[0])  # 输出 "67"

在这个例子中，先造了一个叫memes_67的表，然后再输出那个表内索引是0的数据(请注意，除开lua索引从1开始以外，大多数语言内数组的索引都从0开始)

同时，列表可以修改：

memes_67.append("69")

1.4 条件判断：给程序决定权

条件判断可以让程序在不同情况下做不同的事
拿python代码作为例子：

age = 6767

if age >= 18:
    print("你是成年人")
else:
    print("你是小孩")
    
上面的代码中，我们定义变量age指向数据6767，然后进行条件判断 如果age大于等于18，则输出"你是成年人" 否则(else)输出"你是小孩"

类似"if age >= 18"的式子叫做条件表达式，它最终会变成一个布尔值(True 真的/False 假的) 就会变成：if True或if False
然后再通过这个布尔值来执行哪一个代码
(注意：一般的if条件判断部分是从上往下执行，只要找到一个条件成立的下面就不会走了 这里是一个容易犯错的地方)

1.5 循环：重复执行一段代码

它用于重复执行一个操作，直到满足某个条件为止
一般有2种循环：
1.for循环 用于遍历一个数组

fruits = ["fruit67", "fruit69"]
for fruit in fruits:
    print(fruit)
    
都知道的，造了一个fruits数组，然后一一遍历每个元素

2.while循环：在条件成立时持续执行
例1
count = 0
while count < 5:
    print(count)
    count = count + 1
    
上面代码中，我们定义变量count指向数据0，条件成立（count小于5）一直加，加到count = 5时条件不成立，停止循环
例2
count = 0
while count < 5:
     count = count + 1
     print(count) 
这里可以自行思考一下例1例2输出结果是相同还是不同

1.6 函数：一段打包起来反复利用的代码

这里顺便拓展一下数学中的函数与编程里面的函数
因为编程里面的函数就是从数学里面的继承出来的

编程内：一段打包循环利用的代码

古人为了偷懒，不想ctrl+c和ctrl+v
因此只需要命名并且封装一段代码，就可以循环利用，只需要写它的名字，代入你想要的值，就可以直接调用了

def greet(name):
    print("Hello, " + name)

greet("69")  # 输出 "Hello, 69"

greet是我们定义的函数，name是我们定义的要代入的参数，然后执行了对应操作

数学方面：函数是一种映射

1.6.1 映射的基本定义

一个映射由三个部分组成：

· 定义域：输入值的集合（允许输入的范围）
· 值域：输出值所在的集合（所有可能输出的范围）
· 对应规则：将每个输入映射到唯一一个输出值的规则

如果定义域为X，值域为Y，规则为f，则可以把映射表示为：
f:X -> Y
如果一个X内的元素为x，代入x返回的结果为y，则有：f(x)=y

通俗说法：定义域是“你允许输入什么”，陪域是“可能的输出是什么”，对应规则是“输入被转换成什么”。如果你用这个框架来观察编程中的函数，就能更准确地理解它的作用和局限性。

1.6.2 映射的分类

名称 定义 含义
单射（Injective / 一对一） 不同的输入映射到不同的输出 不存在两个不同的输入产生相同输出
满射（Surjective / 映上） 陪域中的每一个值都至少被一个输入映射到 陪域中没有“未被使用”的元素
双射（Bijective） 既是单射又是满射 每个输入对应唯一输出，每个输出对应唯一输入，存在逆映射

1.6.3 函数是啥

就是把映射搬到数的范围内
例子：如f(x)=x+61，则f(5)=67

1.7 内存模型简述（为Chapter 6打基础）

当你创建一个变量时，系统会在内存中分配一个位置来存储它的值。这个位置可能是“栈”上的一个临时区域，也可能是“堆”上的一块动态存储空间

· 基本类型（数字、布尔值、短字符串） → 通常存储在栈中
· 复杂类型（列表、对象、表） → 通常存储在堆中，变量只存储指向它们的“引用”

这一章你只需要记住这个区别即可，Chapter 6 会详细解释它如何影响函数参数的行为

1.8 模块与库：代码的复用与组织

你已经理解了函数可以把一段代码“打包”起来重复使用。当你的程序逐渐变大时，你可能想把多个相关的函数放在一起，形成一个更大的结构——这就是模块和库的用途。

模块（Module）：一个包含代码的文件

模块是一个包含函数、变量、类等定义的文件。你可以把它看作一个“工具箱”，里面存放着多个相关的工具。

Python 示例：

假设你创建了一个文件 math_utils.py：

# math_utils.py 是一个模块

def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

PI = 3.14159

然后你在另一个文件中导入并使用这个模块：

# main.py
import math_utils

print(math_utils.add(3, 5))       # 输出 8
print(math_utils.multiply(2, 4))  # 输出 8
print(math_utils.PI)              # 输出 3.14159

这样，你就在不同的文件之间复用了代码
