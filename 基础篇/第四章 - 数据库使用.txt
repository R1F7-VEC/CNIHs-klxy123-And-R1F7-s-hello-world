4.1 SQL 基础：增删改查

SQL（Structured Query Language，结构化查询语言）是与关系型数据库（如 MySQL、PostgreSQL、SQLite）交互的标准语言 最重要的操作为CRUD：
（相信你们英语可以）
create：插入数据
read：查询数据
update：修改数据
delete：删除数据

这里的所有示例用SQLite 这是一个轻量级数据库 如果你愿意可以用mysql等其他环境

4.1.1 连接数据库与创建表

python（sqlite3）：

import sqlite3

# 连接到数据库（如果文件不存在，会自动创建）
conn = sqlite3.connect('school.db')
cursor = conn.cursor()

# 创建学生表
cursor.execute('''
CREATE TABLE IF NOT EXISTS students (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    age INTEGER,
    grade REAL
)
''')

conn.commit()
conn.close()

（如果有不会的可以在教程里面找 或者想讲细一点就去问ai）

sqlite3.connect('school.db') 连接或创建数据库文件
CREATE TABLE IF NOT EXISTS 创建表，如果表已存在则不重复创建
id INTEGER PRIMARY KEY AUTOINCREMENT 定义自增主键，每条记录自动生成唯一 ID
TEXT、INTEGER、REAL 是数据类型，分别表示文本、整数、浮点数
NOT NULL 约束表示该字段不能为空
conn.commit() 提交事务，确保改动写入文件
conn.close() 关闭连接，释放资源 防止爆内存

lua（luarocks安装luasqlite3）:
local sqlite3 = require("sqlite3")
local db = sqlite3.open('school.db')
db:exec[[
    CREATE TABLE IF NOT EXISTS students (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        age INTEGER,
        grade REAL
    )
]]
db:close()

4.1.2 插入数据（Create）

用python举例：

import sqlite3

conn = sqlite3.connect('school.db')
cursor = conn.cursor()

# 插入单条数据（使用占位符防止 SQL 注入）
cursor.execute('INSERT INTO students (name, age, grade) VALUES (?, ?, ?)', ('Alice', 14, 88.5))

# 插入多条数据
students = [('Bob', 15, 92.0), ('Charlie', 13, 76.5), ('Diana', 14, 95.0)]
cursor.executemany('INSERT INTO students (name, age, grade) VALUES (?, ?, ?)', students)

conn.commit()
conn.close()

解释：

? 是参数占位符，执行时用元组替换，这是防止 SQL 注入的标准做法
executemany 用于批量插入，效率高于逐条插入
插入后必须 commit() 才会永久保存；如果忘记提交，数据只在当前连接可见

4.1.3 查询数据（Read）

查询所有数据

cursor.execute('SELECT * FROM students')
rows = cursor.fetchall()
for row in rows:
    print(row)
# 输出每条记录，如 (1, 'Alice', 14, 88.5)

条件查询（where）

# 查询年龄大于14的学生
cursor.execute('SELECT name, grade FROM students WHERE age > ?', (14,))
rows = cursor.fetchall()
for name, grade in rows:
    print(f'{name} 的成绩是 {grade}')

排序（order by）

# 按成绩降序排列
cursor.execute('SELECT * FROM students ORDER BY grade DESC')
rows = cursor.fetchall()

聚合查询（AVG、COUNT、SUM）

# 计算平均成绩
cursor.execute('SELECT AVG(grade) FROM students')
avg = cursor.fetchone()[0]
print(f'平均成绩: {avg:.2f}')

# 统计学生总数
cursor.execute('SELECT COUNT(*) FROM students')
count = cursor.fetchone()[0]
print(f'总人数: {count}')

解释：

fetchall() 返回所有结果行的列表
fetchone() 返回第一行结果
WHERE 子句用于过滤条件
ORDER BY 排序，DESC 降序，ASC 升序（默认）

4.1.4 更新数据（Update）

# 更新某个学生的成绩
cursor.execute('UPDATE students SET grade = ? WHERE name = ?', (90.0, 'Alice'))

# 将所有学生的成绩加 5 分（危险操作，通常加条件）
# cursor.execute('UPDATE students SET grade = grade + 5 WHERE age < 15')

conn.commit()

解释：

UPDATE 必须配合 WHERE 条件，否则会更新所有行
更新后也需要 commit() 才能生效

4.1.5 删除数据（Delete）

python
# 删除指定学生
cursor.execute('DELETE FROM students WHERE name = ?', ('Charlie',))

# 删除所有年龄小于 13 的学生
cursor.execute('DELETE FROM students WHERE age < 13')

conn.commit()
解释：

DELETE 同样需要 WHERE 条件，否则会清空整个表
删除操作不可逆，执行前务必确认条件正确

#include <sqlite3.h>
#include <iostream>

int main() {
    sqlite3* db;
    sqlite3_open("school.db", &db);
    char* err = 0;
    sqlite3_exec(db, "SELECT * FROM students", 
        [](void* data, int argc, char** argv, char** colName){

    sqlite3_close(db);
    return 0;
}
4.2 表结构设计与索引

4.2.1 设计原则

合理的表结构是数据库性能和维护性的基础。以下是几个核心原则：

单一职责：每个表只存储一类实体（如学生、课程、成绩）
主键唯一：每张表都应有一个主键，用于唯一标识每条记录
避免冗余：相同数据不应出现在多个表中（通过外键关联）
字段原子性：每个字段只存储一个不可分割的值（如姓名拆分为姓和名）
示例：学生-课程-成绩表设计

学生表 (students)
- id (主键)
- name
- class

课程表 (courses)
- id (主键)
- name
- teacher

成绩表 (scores)
- id (主键)
- student_id (外键 → students.id)
- course_id (外键 → courses.id)
- score
创建关联表

# 创建课程表
cursor.execute('''
CREATE TABLE courses (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    teacher TEXT
)
''')

# 创建成绩表（含外键）
cursor.execute('''
CREATE TABLE scores (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id INTEGER,
    course_id INTEGER,
    score REAL,
    FOREIGN KEY (student_id) REFERENCES students(id),
    FOREIGN KEY (course_id) REFERENCES courses(id)
)
''')
4.2.2 外键约束的作用

外键确保数据一致性：只有 students 表中存在的 id 才能被 scores 表引用。如果试图插入一个不存在的 student_id，SQLite 会报错。启用外键约束（SQLite 默认未开启）：

cursor.execute('PRAGMA foreign_keys = ON')
4.2.3 索引（Index）

索引用于加速查询，类似书的目录。没有索引时，数据库会逐行扫描；有索引后可以直接定位。

创建索引

-- 为 students 表的 name 字段创建索引
CREATE INDEX idx_students_name ON students(name);

-- 为 scores 表的 student_id 和 course_id 组合创建联合索引
CREATE INDEX idx_scores_student_course ON scores(student_id, course_id);
何时使用索引：

经常用于 WHERE、JOIN、ORDER BY 的字段
字段取值区分度高（如 id、name 比 gender 更适合索引）
注意：索引会加快查询速度，但会降低插入、更新、删除的速度（因为需要维护索引结构）。不要为所有字段都创建索引。

Python 创建索引

cursor.execute('CREATE INDEX idx_students_name ON students(name)')
conn.commit()
4.3 事务与一致性

事务是一组数据库操作的逻辑单元，要么全部成功，要么全部失败。事务保证数据的完整性和一致性。

4.3.1 事务的四大特性（ACID）

特性	说明
原子性（Atomicity）	事务中的所有操作要么全部执行，要么全部不执行
一致性（Consistency）	事务完成后，数据库从一个一致状态变到另一个一致状态
隔离性（Isolation）	并发执行的事务互不干扰
持久性（Durability）	事务提交后，更改永久保存
4.3.2 使用事务（Python 示例）

import sqlite3

conn = sqlite3.connect('school.db')
cursor = conn.cursor()

try:
    # 开始事务（SQLite 自动开始，也可显式 BEGIN）
    cursor.execute('BEGIN')

    # 操作1：插入学生
    cursor.execute('INSERT INTO students (name, age) VALUES (?, ?)', ('Eve', 16))

    # 操作2：插入成绩（假设 student_id 是 5）
    cursor.execute('INSERT INTO scores (student_id, course_id, score) VALUES (?, ?, ?)', (5, 1, 85.0))

    # 提交事务
    conn.commit()
    print('事务成功提交')
except Exception as e:
    # 出错时回滚
    conn.rollback()
    print(f'事务回滚: {e}')
finally:
    conn.close()
解释：

如果两个插入操作中任何一个失败，rollback() 会撤销所有操作，数据库状态不变
事务通常用于银行转账、订单处理等需要保证数据一致性的场景
SQLite 默认自动提交每个 execute，但使用 BEGIN 可以显式开启事务
4.3.3 并发与锁

当多个程序同时访问数据库时，可能出现脏读、不可重复读、幻读等问题。SQLite 使用锁机制保证并发安全：

写操作会锁定整个数据库（SQLite 的锁粒度较大）
读操作可以并发进行
生产环境建议使用更强大的数据库（PostgreSQL、MySQL）
在 Python 中，你可以设置超时时间避免长时间等待锁：

conn = sqlite3.connect('school.db', timeout=10)  # 等待锁超时 10 秒
4.4 NoSQL 简介（MongoDB / Redis）

关系型数据库（SQL）擅长处理结构化数据和复杂查询，但在高并发、海量数据、非结构化数据场景下，NoSQL 数据库更有优势。

4.4.1 什么是 NoSQL？

NoSQL（Not Only SQL）指非关系型数据库，它不使用表、行、列的结构，而是采用其他数据模型：

类型	代表	适用场景
文档型	MongoDB	存储 JSON 文档，适合灵活的数据结构
键值型	Redis	缓存、会话存储、计数器
列族型	Cassandra	海量数据写入，分布式存储
图数据库	Neo4j	社交网络、路径查找
4.4.2 MongoDB 入门（Python + pymongo）

安装：pip install pymongo

连接与插入

from pymongo import MongoClient

client = MongoClient('mongodb://localhost:27017')
db = client['school']
collection = db['students']

# 插入一个文档（JSON 对象）
student = {
    'name': 'Alice',
    'age': 14,
    'grade': 88.5,
    'subjects': ['Math', 'Science']  # 数组字段
}
collection.insert_one(student)

# 插入多个
students = [
    {'name': 'Bob', 'age': 15, 'grade': 92.0},
    {'name': 'Charlie', 'age': 13, 'grade': 76.5}
]
collection.insert_many(students)

查询

# 查询所有
for doc in collection.find():
    print(doc)

# 条件查询
for doc in collection.find({'age': {'$gt': 14}}):  # age > 14
    print(doc)

# 按成绩排序
for doc in collection.find().sort('grade', -1):  # -1 降序
    print(doc)
更新

python
collection.update_one(
    {'name': 'Alice'},
    {'$set': {'grade': 90.0}}
)

删除

collection.delete_one({'name': 'Charlie'})
解释：

MongoDB 存储 JSON 格式文档，字段可以灵活变化
查询使用 $gt、$lt、$set 等操作符
不需要预先定义表结构，适合快速迭代
4.4.3 Redis 入门（Python + redis）

Redis 是内存键值数据库，常用于缓存、会话存储、消息队列。

安装：pip install redis

连接与操作

import redis

r = redis.Redis(host='localhost', port=6379, decode_responses=True)

# 字符串
r.set('user:1:name', 'Alice')
print(r.get('user:1:name'))  # 输出 Alice

# 哈希（类似字典）
r.hset('user:1', mapping={'age': 14, 'grade': 88.5})
print(r.hgetall('user:1'))

# 列表
r.lpush('messages', 'Hello', 'World')
print(r.lrange('messages', 0, -1))

# 设置过期时间（秒）
r.setex('session:abc123', 3600, 'user_data')  # 1 小时后过期
解释：

Redis 数据存储在内存中，读写速度极快（微秒级）
数据可以设置过期时间，适合临时存储
支持多种数据结构（字符串、哈希、列表、集合、有序集合）
4.4.4 SQL 与 NoSQL 的选择

维度	SQL	NoSQL
数据结构	固定表结构，适合规范数据	灵活，适合半结构化和非结构化数据
事务	支持强一致性事务	部分支持，通常弱一致性
扩展性	垂直扩展为主（升级硬件）	水平扩展（分布式）
查询能力	复杂查询（多表连接、聚合）	简单查询为主
适用场景	银行、ERP、电商订单	日志、缓存、用户画像、实时分析
实践建议：

大多数业务系统以 SQL 为核心，用 Redis 做缓存
MongoDB 适合文档型数据，如内容管理、用户配置
不要盲目使用 NoSQL，先评估业务需求
4.5 综合实战：学生成绩管理系统

结合本章所有内容，我们构建一个完整的命令行学生成绩管理系统，支持：

添加学生
添加课程
录入成绩
查询所有学生及其平均成绩
完整代码（Python）

python
import sqlite3

def init_db():
    conn = sqlite3.connect('school.db')
    c = conn.cursor()
    c.execute('''CREATE TABLE IF NOT EXISTS students
                 (id INTEGER PRIMARY KEY, name TEXT)''')
    c.execute('''CREATE TABLE IF NOT EXISTS courses
                 (id INTEGER PRIMARY KEY, name TEXT)''')
    c.execute('''CREATE TABLE IF NOT EXISTS scores
                 (student_id INTEGER, course_id INTEGER, score REAL,
                  FOREIGN KEY(student_id) REFERENCES students(id),
                  FOREIGN KEY(course_id) REFERENCES courses(id))''')
    conn.commit()
    conn.close()

def add_student(name):
    conn = sqlite3.connect('school.db')
    c = conn.cursor()
    c.execute('INSERT INTO students (name) VALUES (?)', (name,))
    conn.commit()
    conn.close()

def add_course(name):
    conn = sqlite3.connect('school.db')
    c = conn.cursor()
    c.execute('INSERT INTO courses (name) VALUES (?)', (name,))
    conn.commit()
    conn.close()

def add_score(student_name, course_name, score):
    conn = sqlite3.connect('school.db')
    c = conn.cursor()
    # 获取 student_id
    c.execute('SELECT id FROM students WHERE name=?', (student_name,))
    student_id = c.fetchone()[0]
    c.execute('SELECT id FROM courses WHERE name=?', (course_name,))
    course_id = c.fetchone()[0]
    c.execute('INSERT INTO scores (student_id, course_id, score) VALUES (?, ?, ?)',
              (student_id, course_id, score))
    conn.commit()
    conn.close()

def query_student_avg():
    conn = sqlite3.connect('school.db')
    c = conn.cursor()
    c.execute('''
        SELECT students.name, AVG(scores.score) as avg_score
        FROM students
        LEFT JOIN scores ON students.id = scores.student_id
        GROUP BY students.id
        ORDER BY avg_score DESC
    ''')
    rows = c.fetchall()
    for name, avg in rows:
        avg_display = f'{avg:.2f}' if avg is not None else '无成绩'
        print(f'{name}: {avg_display}')
    conn.close()

def main():
    init_db()
    while True:
        print('\n1. 添加学生')
        print('2. 添加课程')
        print('3. 录入成绩')
        print('4. 查询平均成绩')
        print('5. 退出')
        choice = input('请选择: ')
        if choice == '1':
            name = input('学生姓名: ')
            add_student(name)
        elif choice == '2':
            name = input('课程名称: ')
            add_course(name)
        elif choice == '3':
            s_name = input('学生姓名: ')
            c_name = input('课程名称: ')
            score = float(input('成绩: '))
            add_score(s_name, c_name, score)
        elif choice == '4':
            query_student_avg()
        elif choice == '5':
            break

if __name__ == '__main__':
    main()
这个程序将你学过的 SQL 操作整合成一个完整的应用，涵盖了 CRUD、表关联、聚合查询、外键约束等核心概念。
