9.1 什么是机器学习？

传统编程中，我们明确告诉计算机每一步该怎么做. 而在机器学习中，我们给计算机提供数据和期望的输出，让它自己找到规则

9.1.1 机器学习 vs 传统编程

维度	传统编程		机器学习
输入	数据 + 规则		数据 + 答案
输出	答案			规则（模型）
例子	写一个函数计算平方	给一堆数字和它们的平方，让程序自己学习平方的规律

依旧python举例子：

# 传统编程：我们告诉计算机规则
def square(x):
    return x * x

# 机器学习：让计算机自己找出规则
# 输入：X = [1, 2, 3, 4, 5]，Y = [1, 4, 9, 16, 25]
# 输出：模型自动学到 f(x) = x * x

9.1.2 机器学习的三大类型

监督学习：有标签的数据（已标注答案），如垃圾邮件分类、房价预测
无监督学习：无标签数据，让模型自己发现结构，如客户分群
强化学习：通过奖励和惩罚学习策略，如下围棋

9.3 回归与分类

回归和分类是最常见的监督学习任务. 回归预测连续值（如房价），分类预测离散值（如垃圾邮件）

9.3.1 线性回归

线性回归试图找到一条直线（或超平面），使得所有数据点到这条直线的距离平方和最小

原理：y = w_1·x_1 + w_2·x_2 + ... + w_n·x_n + b

w_i是特征权重

b 是偏置项
模型训练的目标：找到最优w和b，使预测值与真实值的误差最小

from sklearn.linear_model import LinearRegression

# 模拟数据
X = [[50], [60], [70], [80], [90], [100], [110], [120]]
y = [150, 180, 210, 240, 280, 310, 340, 380]

# 训练模型
model = LinearRegression()
model.fit(X, y)

# 预测
print(model.predict([[130]]))  # 预测 130m² 的房价
print(f"系数: {model.coef_[0]:.2f}, 截距: {model.intercept_:.2f}")

9.3.2 逻辑回归

虽然名称带“回归”，但逻辑回归实际上是一种分类算法，用于二分类问题（输出0或1）

from sklearn.linear_model import LogisticRegression

# 示例：根据面积判断是否超过200万
y = [0, 0, 0, 0, 1, 1, 1, 1]  # 0表示低于200万，1表示高于200万

model = LogisticRegression()
model.fit(X, y)

# 预测
print(model.predict([[75]]))  # 预测75m²的房屋价格是否超过200万

9.4 神经网络入门

神经网络是深度学习的核心，它模拟了人脑神经元的结构——通过多层非线性变换来学习复杂模式

9.4.1 神经元

一个神经元接收输入，加权求和后经过一个激活函数，产生输出
（懒得打字只想用英文 lol）
output = Activation_Function(w_1·x_1 + ... + w_n·x_n + b)

9.4.2 简单神经网络实现

import numpy as np

class SimpleNeuralNetwork:
    def __init__(self, input_size, hidden_size, output_size):
        # 初始化权重和偏置（随机）
        self.W1 = np.random.randn(input_size, hidden_size) * 0.01
        self.b1 = np.zeros((1, hidden_size))
        self.W2 = np.random.randn(hidden_size, output_size) * 0.01
        self.b2 = np.zeros((1, output_size))

    def forward(self, X):
        # 前向传播
        self.z1 = np.dot(X, self.W1) + self.b1
        self.a1 = np.tanh(self.z1)  # 激活函数
        self.z2 = np.dot(self.a1, self.W2) + self.b2
        self.a2 = np.tanh(self.z2)
        return self.a2

    def train(self, X, y, learning_rate=0.01, epochs=1000):
        # 训练模型（简化版，使用梯度下降）
        for i in range(epochs):
            # 前向传播
            output = self.forward(X)
            # 计算损失
            loss = np.mean((output - y) ** 2)
            if i % 100 == 0:
                print(f"Epoch {i}, Loss: {loss:.4f}")

# 测试
model = SimpleNeuralNetwork(2, 4, 1)
X_test = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
print(model.forward(X_test))

这个简单的网络实现了XOR逻辑运算的初步功能，展示了神经网络的基本结构

9.5 数学拓展 · 线性代数入门

线性代数是机器学习、计算机图形学、物理模拟等领域的基础数学工具. 它让数据、变换和空间结构变得可计算

9.5.1 向量

向量是有序的数字列表，可以表示数据点（如用户画像、文本特征）、方向（如速度、加速度）、坐标位置等
					   →
在高二数学里面向量表示有大小和方向的量 如：a 在数学中，向量可以表示为有序数组，每个元素对应一个维度上的分量，just like：二维向量 v = [v_1, v_2]

向量也可以加减乘除

加法与减法：仅同维度向量可加减，对应分量相加减，几何上遵循平行四边形法则

标量乘法：向量与标量c相乘，每个分量乘以c，几何上表示向量长度缩放，方向保持或反向

线性组合：一个向量集合{v_1, v_2, ... , v_n}和标量集合{a_1, a_2, a_3, ... , a_n} 线性组合为：a_1·v_1 + ... + a_n·v_n

其他概念（基向量、单位向量、点积、法向量等）到了域外数学篇再讲

Python 向量运算

import numpy as np

v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])

print(v1 + v2)        # [5, 7, 9]
print(np.dot(v1, v2)) # 点积: 1*4 + 2*5 + 3*6 = 32
print(np.linalg.norm(v1)) # 长度: sqrt(1+4+9)

9.5.2 矩阵

矩阵是二维数组，用于表示线性变换（如旋转、缩放、投影）、数据集（每一行是一个样本，每一列是一个特征），以及神经网络中的权重
由数域F中钓 m·n 个数a_ij （i=1, 2, 3, ... , m；j=1,2, ... , n） 排成的m行n列的矩形数表，称为数域F中的一个m·n 矩阵.

9.5.3 矩阵乘法

矩阵乘法是线性代数中最核心的运算. 两个矩阵A(m·n)和B(n·p)相乘，结果是一个 m·p的矩阵. 矩阵乘法要求A的列数等于B的行数

9.5.4 线性代数的核心概念

特征值和特征向量：在线性变换中，某些方向上的向量只被缩放，方向不变，这些就是特征向量。特征值和特征向量在降维（PCA）、图论、量子力学等领域有广泛应用

奇异值分解（SVD）：将任意矩阵分解为三个简单矩阵的乘积，是推荐系统、图像压缩、自然语言处理的基础

线性变换：矩阵可以表示空间中的各种变换——旋转、缩放、投影等. 理解矩阵就是理解“空间如何被扭曲”. 这在机器学习中意味着：我们试图找到一个线性边界，将不同类别的数据分开
