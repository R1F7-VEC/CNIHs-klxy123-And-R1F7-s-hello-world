7.1 加密算法实现

加密是将明文转换为密文的过程，解密则是将密文恢复为明文. 加密算法分为两大类：对称加密和非对称加密. 

7.1.1 对称加密

对称加密使用同一个密钥进行加密和解密. 加密和解密速度快，适合大量数据的加密，但密钥分发困难. 

常见对称加密算法：

AES（Advanced Encryption Standard）：目前程序猿最爱的对称加密标准
DES（Data Encryption Standard）：较老的标准，已被破解
ChaCha20：谷歌推荐的高性能流加密算法

AES 加密示例（Python + cryptography 库）

安装依赖（在你的终端操作）：

pip3 install cryptography

代码：

from cryptography.hazmat.primitives.ciphers import Cipher, algorithms, modes
from cryptography.hazmat.backends import default_backend
import os

def aes_encrypt(key, plaintext):
    """使用 aes 加密（gcm 模式）"""
    iv = os.urandom(16)  # 随机生成初始化向量
    cipher = Cipher(algorithms.AES(key), modes.GCM(iv), backend=default_backend())
    encryptor = cipher.encryptor()
    ciphertext = encryptor.update(plaintext.encode('utf-8')) + encryptor.finalize()
    return iv + encryptor.tag + ciphertext

def aes_decrypt(key, ciphertext):
    """使用 AES 解密"""
    iv = ciphertext[:16]
    tag = ciphertext[16:32]
    actual_ciphertext = ciphertext[32:]
    cipher = Cipher(algorithms.AES(key), modes.GCM(iv, tag), backend=default_backend())
    decryptor = cipher.decryptor()
    plaintext = decryptor.update(actual_ciphertext) + decryptor.finalize()
    return plaintext.decode('utf-8')

# 使用
key = os.urandom(32)  # 256 位密钥
plaintext = "Hello, 这是机密信息！"
encrypted = aes_encrypt(key, plaintext)
decrypted = aes_decrypt(key, encrypted)
print(f"原文: {plaintext}")
print(f"解密后: {decrypted}")

对称加密的优缺点：

优点			缺点
加密速度快		密钥分发困难
适合大数据量加密	每对通信方需要共享一个密钥
实现简单		密钥数量随用户数平方增长

7.1.2 非对称加密

非对称加密使用一对密钥：公钥（Public Key）和私钥（Private Key）. 公钥可以公开，私钥必须保密（否则你的数据就等掉吧）. 用公钥加密的数据只能用私钥解密，用私钥签名的数据只能用公钥验证

常见非对称加密算法：

RSA：最常用的非对称加密算法
ECC（椭圆曲线加密）：更高效，密钥更短
Diffie-Hellman：用于密钥交换

RSA 加密示例（Python + cryptography 库）

from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.backends import default_backend

# 生成 RSA 密钥对
private_key = rsa.generate_private_key(
    public_exponent=65537,
    key_size=2048,
    backend=default_backend()
)
public_key = private_key.public_key()

# 使用公钥加密
message = b"Hello, 这是用 RSA 加密的消息！"
ciphertext = public_key.encrypt(
    message,
    padding.OAEP(
        mgf=padding.MGF1(algorithm=hashes.SHA256()),
        algorithm=hashes.SHA256(),
        label=None
    )
)

# 使用私钥解密
plaintext = private_key.decrypt(
    ciphertext,
    padding.OAEP(
        mgf=padding.MGF1(algorithm=hashes.SHA256()),
        algorithm=hashes.SHA256(),
        label=None
    )
)

print(f"原文: {message.decode('utf-8')}")
print(f"解密后: {plaintext.decode('utf-8')}")

对称加密 vs 非对称加密：

维度		对称加密	非对称加密
密钥数量	1 个		2 个（公钥 + 私钥）
加密速度	快		慢（约慢 100-1000 倍）
密钥分发	困难		简单（公钥可公开）
典型用途	数据加密	密钥交换、数字签名

实际应用中的混合加密：

使用非对称加密传输对称密钥
使用对称加密传输实际数据
是 HTTPS/TLS 的工作原理

7.2 数字签名与身份认证

数字签名用于验证消息的真实性（确实由发送者发出）和完整性（未被篡改）. 身份认证用于确认用户的身份

7.2.1 数字签名

数字签名通过私钥对消息的哈希值加密生成，接收者用公钥验证

Python 数字签名示例：

from cryptography.hazmat.primitives.asymmetric import rsa, padding
from cryptography.hazmat.primitives import hashes

# 生成密钥对
private_key = rsa.generate_private_key(
    public_exponent=65537,
    key_size=2048,
    backend=default_backend()
)
public_key = private_key.public_key()

# 签名
message = b"这是一条重要消息"
signature = private_key.sign(
    message,
    padding.PSS(
        mgf=padding.MGF1(hashes.SHA256()),
        salt_length=padding.PSS.MAX_LENGTH
    ),
    hashes.SHA256()
)

# 验证签名
try:
    public_key.verify(
        signature,
        message,
        padding.PSS(
            mgf=padding.MGF1(hashes.SHA256()),
            salt_length=padding.PSS.MAX_LENGTH
        ),
        hashes.SHA256()
    )
    print("签名验证通过")
except Exception:
    print("签名验证失败")

7.2.2 哈希函数

哈希函数将任意长度的数据映射为固定长度的输出

常见哈希算法：

MD5：已不安全
SHA-1：已被神秘黑客攻破
SHA-256 / SHA-3：当前安全标准

Python 哈希示例：

import hashlib

def get_hash(data):
    return hashlib.sha256(data.encode('utf-8')).hexdigest()

message1 = "Hello"
message2 = "Hello!"
print(f"'{message1}' → {get_hash(message1)}")
print(f"'{message2}' → {get_hash(message2)}")
# 两个哈希值完全不同（雪崩效应）

7.2.3 JWT（JSON Web Token）

JWT 是一种紧凑的、自包含的认证方案. 由三部分组成：Header.Payload.Signature

JWT 示例（Python + PyJWT）：

在终端输入命令：pip install pyjwt

import jwt
import datetime

SECRET_KEY = "your-secret-key"  # 实际应用中应使用环境变量

def generate_token(user_id):
    payload = {
        'user_id': user_id,
        'exp': datetime.datetime.utcnow() + datetime.timedelta(hours=1)
    }
    return jwt.encode(payload, SECRET_KEY, algorithm='HS256')

def verify_token(token):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=['HS256'])
        return payload['user_id']
    except jwt.ExpiredSignatureError:
        return "Token 已过期"
    except jwt.InvalidTokenError:
        return "无效 Token"

token = generate_token(123)
print(f"Token: {token}")
print(f"验证结果: {verify_token(token)}")

7.3 安全协议

7.3.1 TLS/SSL

TLS（Transport Layer Security）是 HTTPS 的基础协议，提供加密、认证和完整性保护

TLS 握手过程（简化版）：

客户端向服务器发送 Hello 消息（支持的加密套件）
服务器返回 Hello 消息（选定的加密套件 + 证书）

7.4.1 模拟 SQL 注入攻击与防御

攻击原理：攻击者在输入中插入恶意 SQL 代码，使数据库执行非预期的查询

脆弱代码（存在漏洞）：

import sqlite3

# 漏洞代码：直接将用户输入拼接到 SQL 查询中
def vulnerable_login(username, password):
    conn = sqlite3.connect(':memory:')
    c = conn.cursor()
    c.execute('CREATE TABLE users (username TEXT, password TEXT)')
    c.execute("INSERT INTO users VALUES ('admin', 'password123')")
    conn.commit()
    # 危险：直接拼接字符串
    query = f"SELECT * FROM users WHERE username = '{username}' AND password = '{password}'"
    print(f"[SQL] 执行的查询: {query}")
    c.execute(query)
    return c.fetchone()

# 攻击示例：输入 username = "' OR '1'='1' --"
# 查询变成: SELECT * FROM users WHERE username = '' OR '1'='1' --' AND password = ''
print(vulnerable_login("' OR '1'='1' --", ""))

安全代码（参数化查询防御）：

def safe_login(username, password):
    conn = sqlite3.connect(':memory:')
    c = conn.cursor()
    c.execute('CREATE TABLE users (username TEXT, password TEXT)')
    c.execute("INSERT INTO users VALUES ('admin', 'password123')")
    conn.commit()
    # 安全：使用参数化查询
    c.execute('SELECT * FROM users WHERE username = ? AND password = ?', (username, password))
    return c.fetchone()

print(safe_login("admin", "password123"))  # 正常登录
print(safe_login("' OR '1'='1' --", ""))   # 返回 None，攻击失败

7.4.2 模拟 XSS（跨站脚本攻击）与防御

攻击原理：攻击者在网页中注入恶意 JavaScript 代码

漏洞代码（Flask）：

from flask import Flask, request

app = Flask(__name__)

@app.route('/vulnerable_comment', methods=['POST'])
def vulnerable_comment():
    content = request.form.get('content', '')
    # 危险：直接输出用户输入，不进行转义
    return f'<div class="comment">{content}</div>'

防御代码（转义输出）：

from flask import Flask, request, escape

app = Flask(__name__)

@app.route('/safe_comment', methods=['POST'])
def safe_comment():
    content = request.form.get('content', '')
    # 转义 HTML 特殊字符，防止 XSS
    safe_content = escape(content)
    return f'<div class="comment">{safe_content}</div>'

7.4.3 模拟 CSRF（跨站请求伪造）与防御

攻击原理：攻击者诱导用户点击恶意链接，在用户已登录的情况下发送伪造请求

防御方案（CSRF Token）：

import secrets
from flask import Flask, session, request

app = Flask(__name__)
app.secret_key = 'your-secret-key'

@app.route('/form')
def form():
    token = secrets.token_hex(16)
    session['csrf_token'] = token
    return f'''
    <form action="/submit" method="POST">
        <input type="hidden" name="csrf_token" value="{token}">
        <input type="text" name="data">
        <input type="submit">
    </form>
    '''

@app.route('/submit', methods=['POST'])
def submit():
    if request.form.get('csrf_token') != session.get('csrf_token'):
        return "CSRF 验证失败，可能是伪造请求！", 403
    return "提交成功"

7.4.4 模拟 DDoS 攻击与防御（低强度模拟）

注意：以下代码仅供学习攻击原理，严禁用于攻击真实服务器！

模拟攻击代码（低强度）：

import threading
import requests
import time

def flood(target_url, num_requests):
    """模拟 DDoS 攻击（仅供学习！请勿攻击真实网站！）"""
    def send_request():
        try:
            response = requests.get(target_url, timeout=1)
            print(f"状态: {response.status_code}")
        except:
            print("请求失败")

    print(f"[攻击模拟] 开始向 {target_url} 发送 {num_requests} 个请求...")
    threads = []
    for _ in range(num_requests):
        thread = threading.Thread(target=send_request)
        thread.start()
        threads.append(thread)

    for thread in threads:
        thread.join()
    print("[攻击模拟] 完成")

防御策略：

限流（Rate Limiting）：限制每个IP的请求频率
使用CDN和WAF
增加服务器资源
识别并封堵恶意流量

（当然，汝可通过Fail2ban等诸如此类之工具以限流也（古人云） 在这里提供一下python的方法）

import time
from collections import defaultdict

class RateLimiter:
    def __init__(self, max_requests, time_window):
        self.max_requests = max_requests
        self.time_window = time_window
        self.requests = defaultdict(list)

    def allow_request(self, client_id):
        now = time.time()
        # 清理过期记录
        self.requests[client_id] = [
            timestamp for timestamp in self.requests[client_id]
            if now - timestamp < self.time_window
        ]
        if len(self.requests[client_id]) < self.max_requests:
            self.requests[client_id].append(now)
            return True
        return False

# 使用：限制每个IP每10秒最多5个请求
limiter = RateLimiter(5, 10)
print(f"允许请求: {limiter.allow_request('192.168.1.1')}")  # True
print(f"允许请求: {limiter.allow_request('192.168.1.1')}")  # 连续请求5次后
print(f"允许请求: {limiter.allow_request('192.168.1.1')}")  # 第6次返回False

7.5.1 整除与素数

对任意给的两个整数a、b不等于0，如果存在整数q，使得b=aq，那么称b能被a整除（a能整除b）即a | b
如果一个数p从1到p之内除了1和他本身没有因数，那么p是素数（质数），反之则为合数

就有一堆性质 像a|b, b|c => a|c这种的

（域外数学篇会提到）

素数判定：

def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

这里用了一个定理：如果对一个（1，根号n]之间的素数p，都有p不整除n，那么n是素数

证明 事实上，如果n为合数，就有n=pq（2<= p <= q） 所以p的平方小于n 开方即可

算术基本定理：任意大于1的整数可以唯一分解为素数的乘积

7.5.2 同余与快速幂

同余：若a和b除以m的余数相同，记作 a≡b(modm).

快速幂取模：def mod_pow(base, exp, mod):
    result = 1
    base = base % mod
    while exp > 0:
        if exp % 2 == 1:
            result = (result * base) % mod
        base = (base * base) % mod
        exp //= 2
    return result

7.5.3 欧拉函数与欧拉定理

欧拉函数φ(n) （念phi）表示小于等于n并且和n互质的数的个数

（gcd(a, n)表示a与n的最大公因数 在书面上记作(a, n) 最小公倍数就是[a, n] 自己可以重新学一下小学奥数）

欧拉定理：若gcd(a,n)=1，则a的phi(n)次方≡1 (mod n). 

def euler_phi(n):
    result = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1
    if n > 1:
        result -= result // n
    return result

7.5.4 RSA 的数学原理

RSA 加密算法基于大数分解的困难性

密钥生成：

选择两个大素数p和q
计算n=pq，phi(n)=(p-1)(q-1)
选个数字e让gcd(e, phi(n)) = 1
算出满足ed ≡ 1 (mod phi(n))
公钥和私钥：(e, n) (d, n)

加密：c ≡ m的e次方(mod n)
解密：m ≡ c的d次方(mod n)
